# 口播稿写法

## 选题五问（全过才写）
1. 时效：最近有新进展，或说得清旧话题为什么又被讨论。
2. 普适：不把个案说成全行业。
3. 一手材料：有原始来源；证据断了就写"目前无法断定"。
4. 去情绪后仍有价值：删掉情绪词还剩下信息。
5. 叙事轮换：不连续用同一套路（原理 / 过程 / 对比 / 案例轮换）。

## 钩子（前 3–10 秒）
- 第二人称 + 反直觉："你已经……，为什么还……？"
- 开头不讲历史、不出术语；第一句就进入冲突。
- 用"所以，……"一句点出核心观点。

## 口语化
- 短句，一句一个意思；每句不超过两个字幕块（每块 ≤14 字）。
- 用"你"，多用类比（"像一个刚入职的实习生"）。
- 数字、英文给 TTS 另写读法（`tts` 字段）。

## 不能写的
- 绝对化承诺：保证、一定、100%、稳赚、躺赚、最好、第一（无依据时）。
- 编造热度和数据；没有可验证来源的说法直接删，不要改写成模糊说法。
- 转述他人观点要标明"据……"。

## 结尾
- 一个人人答得上的互动问题（不考知识点）；CTA 可选，说完 0.3 秒内结束。

## 出处
每个事实 / 数字一行：来源名称、链接、访问日期。屏幕上出现的数字必须能在出处中找到；示意数据要标"示意"。
