# 配音规则

- 服务：本地 Voicebox（默认 `http://127.0.0.1:17493`，`/health`、`/profiles`、`/generate/stream`，失败退回 `/generate` + 轮询）。地址和声音档案 id 只用 `VOICEBOX_URL` / `VOICEBOX_PROFILE_ID` 或本地 `config.json` 配置，不提交进仓库。
- 声音档案需本人授权；只用于本人认可的内容。平台要求时标注"AI 生成"。
- 语言设为 `zh`；数字、英文缩写写成好读的 `tts` 文本。
- **每段生成 1 遍**。然后 `asr_check.py` 转写比对（按拼音算错误率，默认阈值 0.05），**只重生成**列在 `REGENERATE` 里的段（`--only`）。
- 连续 3 次失败就停，先排查服务（可能被其他任务占用或模型在下载），不要死循环重试。单次请求超时默认 600 秒。
- 拼接（`assemble_voice.py`）：去掉每段首尾静音；段内超过 `max_gap`（0.45s）的停顿从中间切，**保留 ≥0.28s**；段间插 `seg_gap`（0.20s）；整体峰值归一到 -1 dBFS 左右，最终响度在成片阶段统一做。
- 有 ASR 结果时用 ASR 词时间生成逐字时间轴；没有就按时长均分（字幕会略不准，适合样片）。
- 语速：如需加速，用不变调的方式（如 ffmpeg `atempo`）在生成时间轴**之前**处理，不要事后拉伸视频。
