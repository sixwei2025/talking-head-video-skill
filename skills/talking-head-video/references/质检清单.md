# 质检清单

## 自动（`scripts/qc.py`，报告写 `build/qc.txt`）
| 项 | 命令要点 | 通过标准 |
|---|---|---|
| 规格 | ffprobe | 1080×1920，H.264，AAC 48k，有音轨 |
| 黑帧 | `blackdetect=d=0.1:pix_th=0.05` | 无 |
| 冻帧 | `freezedetect=n=-60dB:d=2` | 无 |
| 静音 | `silencedetect=n=-40dB:d=0.3` | 正文内无；结尾留白 ≤0.3s |
| 响度 | `loudnorm=print_format=json` | -16～-12 LUFS，TP ≤ -1 dBTP |
| 首帧 | 第 0 帧 vs 第 4 帧 | 平均差 >3 |

## 人工
- [ ] 完整看一遍：回答了开头提出的问题吗？
- [ ] 声画对得上；字幕与语音逐字同步，无错字、无折行
- [ ] 屏幕上的数字 / 单位 / 名称都能在出处里找到
- [ ] 只有指定声音，无杂音、无爆音
- [ ] 无绝对化承诺、无未授权素材、无个人隐私信息
- [ ] 结尾说完 0.3 秒内结束
- [ ] `deliver/` 只有成片和发布说明
