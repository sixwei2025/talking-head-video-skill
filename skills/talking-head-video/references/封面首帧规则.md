# 视频封面与 0.01s 首帧规则（2026-11-13 升级版：竖屏 3:4 封面 + 横屏 16:9 首帧）

## 一、核心画幅铁律
1. **双画幅同步产出**：
   - **独立发布封面（竖屏 `3:4`）**：`1080×1440`（默认 `--dpr 2` 输出 `2160×2880` 超清 `cover-3x4.png` 与 `cover-3x4.jpg`），用于视频号、小红书、B站与本地视频中心（`~/video-hub`）上传独立竖版封面。
   - **成片 0.01s 首帧（横屏 `16:9`）**：`1920×1080`（`cover-opening.png` / `cover-16x9.png`），直接压入横屏成片第 `0–2` 帧（`0.1s` @30fps），确保平台在 `0.01s` 抓帧时就是完整高颜值海报，第 3 帧切入正文，不做黑场淡入。
   - 若平台自动从 `16:9` 首帧中央裁切 `3:4`，可加 `--center-safe-16x9` 让全部标题严格收敛在中央 `810×1080`（`x: 555..1365`）安全区内。

  2. `joeseesun/qiaomu-html-cover`：0.5 秒停留测试（200px 缩略图依然秒读主标题）+ 离线 CJK 可变字体确定性排版。
  3. `ponyodong2026/ponyo-cover-anchor-system`：点击率 = 信息密度 × 视觉锚点（人像 / 巨型数字 / 真实界面 / 宣言大字）。
  4. `WhiteTowerAI/cut-as-code`：Almanac / Editorial / Swiss Grid 卡片 Token。

## 三、6+1 套主题 (`--theme`) 与 4 大版式 (`--layout`)
- **主题 (`--theme`)**：
  - `swiss_dark`（默认）：暗夜瑞士网格 `#0A0A0C` + `#F2F0ED` + `#C8102E` 汇芯红 + `72px` 建筑网格（AI 工具 / GitHub 开源 / 教程首选）
  - `midnight`：午夜墨 `#0E0D0C` + `#ECE2CF` 暖白 + `#D4A04A` 香槟金（商业变现 / 深度复盘）
  - `paper`：纸本墨 `#F1EFEA` + `#0A0A0B` + `#C8102E` 汇芯红（方法论 / 清单 / 教程）
  - `kraft`：牛皮纸 `#EEDFC7` + `#2A1E13` + `#9B5A2E` 焦糖（个人经历 / 故事复盘）
  - `indigo`：靛蓝瓷 `#F1F3F5` + `#0A1F3D` + `#315D93`（SaaS 演示 / 企业级方案）
  - `swiss_klein`：瑞士克莱因蓝 `#FAFAF8` + `#002FA7`（榜单盘点 / 极客横评）
  - `brand`：汇芯红 `#FAF7F4` + `#C8102E`（品牌标准白底红锚点）
- **版式 (`--layout`)**：
  - `swiss-metric`：瑞士巨型数字风（`260~300px` Tabular 巨型数字如 `322K★` / `10X` + 双行大字）
  - `editorial-portrait`：杂志真人锚点风（内置 `assets/owner_cutout_hd.png` 精修人像，选择性压高光保留肤色，**严禁纯黑白**，顶部渐变绝不遮挡发顶）
  - `ui-showcase`：真实界面画框风（上方大字钩子 + 下方真实软件截图 macOS 极简画框）
  - `manifesto-poster`：极简宣言大字风（瑞士网格大字报 + 建筑感留白）

## 四、一键调用命令
```bash
# 生成单条视频的 3:4 竖版封面 + 16:9 横屏首帧
/opt/homebrew/bin/python3.11 scripts/render_video_cover.py \
  --title "全自动剪辑视频|10分钟出大片" \
  --kicker "GITHUB · 实操" \
  --brand "OpenMontage" \
  --metric "322K★" \
  --theme swiss_dark \
  --out build/cover/

# 一次预览 6 套样板间 + Contact Sheet 总览图
/opt/homebrew/bin/python3.11 scripts/render_video_cover.py --demo --out /tmp/cover_demo
```
