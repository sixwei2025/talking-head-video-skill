# 封面首帧规则

- 平台（如视频号）默认在约 0.01 秒取缩略图，所以**封面直接做成第 0 帧**，不另外上传也能显示正确封面。
- 封面停 3 帧（30fps 约 0.1 秒），第 3 帧开始正文；不做淡入，不留黑场。
- 版式：大字标题 ≤12 字、2–3 行，位于 y480–1100；左侧强调色竖条；不放二维码、联系方式。
- 封面大字要与开头钩子呼应，不做标题党承诺。
- 同时导出 `build/cover.png`（`ffmpeg -i final.mp4 -frames:v 1`），供需要单独上传封面的平台使用。
- 质检：`qc.py` 比较第 0 帧和第 4 帧，平均差 >3 说明封面确实是独立首帧。
